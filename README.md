# 学园破拆 —— 3D 校园破坏模拟（超大规模版）

> 在线地址：https://yh081030.github.io/campus_destroy/

完全虚构的 3D 场景（不做任何真实地点参考、无任何地名/校名命名）：

- **M校**（初中部，直径约 **2km**）：教学楼×4 + 图书馆 + 宿舍×3 + 食堂×3 + 体育馆×3
  + **足球场**、篮球场、停车场、**大湖**（湖心亭+栈桥）
- **D校**（高中部，直径约 **1.5km**）：教学楼×4 + **扩建新翼**（玻璃幕墙+连廊）+
  体育馆×2 + 食堂×3、**足球场**、篮球场、停车场（**无宿舍**）
- 校内建筑**非常密集**（两校合计约 50 栋、近 3 万可破坏构件）
- 两校区之间由一条 **5.4km 长主干道**连接；另有一条贯穿全图的北侧支路；
  道路两侧分布**随机掩体**（隔离墩/沙袋/混凝土块/木箱）与**路牌**（M校/D校/撤离点指路牌+警示牌）
- 围墙设有**主校门 + 多个侧门缺口**，也可直接**翻越围墙**（贴墙按跳跃键，消耗体力）
- NPC 全部为**异化怪物**（无任何人类形象），头顶**血条**，血条清零即击杀；
  普通怪**数量与刷新速度大幅提升**，且**全部配备远程武器**
- 校门仅以字母 **A / B** 标识，无任何学校命名

## 玩法
1. 主菜单选择难度 **F / E / D / C / B / A / S / SS / SSS / SSS+**（普通→深渊），决定：
   - 建筑生命与价值倍率（难度越高越坚固、越值钱）
   - 怪物生命/伤害/速度、初始数量（200→1200）、裂隙刷新频率
   - **结算奖励比例 5% → 100%**
2. 进入行动：消灭全部怪物 + 摧毁 **12 座裂隙传送门**（每座造价 1000 万美元）＝ **大胜**；
   可驻留任意时间，从任意**撤离门**离开即结算；
   **阵亡/放弃 = 失败，但破坏价值仍按最低 5% 结算**，已入账击杀奖金保留。
3. 破坏一切（建筑、道路、树木、设施、掩体、路牌）获得**破坏价值**；撤离时按 `破坏价值 × 奖励比例` 结算 USD。
4. 空间背包**无容量限制**；弹药需购买；**载具被摧毁即消耗**。
5. 怪物会**游击进攻 / 守卫学校 / 支援另一个校区**；残骸不会消失，可作掩体，再次击打可彻底毁坏；
   生命低于 35% 会减速、瞄准变差；护甲吸收伤害。
6. **账号与排行榜**：注册/登录（密码加盐哈希存储），每局结算自动上传成绩，
   排行榜按破坏价值降序（前100名），支持云端+本地双存储。

## 操作（手机触控，自动检测，横屏适配）
- **左摇杆**（固定左下）：移动，推满=冲刺；**右摇杆**（固定右下）：瞄准，推到底=自动开火
- 红色开火键：**点击=切换连发**；**按住拖出按钮后松手=单发**
- 其余按钮：锁定 / 跳跃 / 换弹 / 手雷 / 互动 / **上车** / 武器 / 商店 / 菜单
- 竖屏时显示"请旋转屏幕"提示，进入行动自动尝试锁定横屏

## 装备（USD 计价）
- 冷兵器：战术小刀、棒球棍、长剑、法杖（法杖更长更慢）
- 枪械：手枪 / 冲锋枪 / 霰弹枪 / 突击步枪 / 狙击枪 / 轻机枪
- 重火力：手榴弹 / 火箭筒 / 迫击炮（高抛弹道，最小射程30米、最远340米）/
  **导弹**（射程无限，发射后地图点选打击点，威力巨大）
- 护甲：防弹衣 / 头盔 / 重装护甲 / 护甲修复包
- 载具：自行车 / 电动车 / 摩托车 / 轿车 / 挖掘机（机械臂高效拆楼）/
  装甲车（车载机枪）/ 坦克（主炮）/ 武装直升机（火箭）/ 轰炸机（航弹）

## 其它特性
- 昼夜随系统时间自动切换，也可在主菜单手动选择**白天 / 黑夜 / 自动**
- 校内道路、停车场（停放不可驾驶汽车）、车棚（停放自行车/电动车）
- 骑乘自行车/电动车/摩托车/轿车时可正常使用随身武器射击
- 下车时载具**自动收回空间背包**（商店车库），方便再次部署

## 升级（全部线性成长，非指数）
- 身体素质：生命上限、移动速度、跳跃高度、近战威力、护甲上限
- **转职路线（可双修）**：战士转职（+近战伤害/+生命）、魔法师转职（+远程伤害/+移速）
- **飞行能力**：战士+魔法师合计≥10级后可解锁，空中按住跳跃上升、Ctrl下降（消耗体力）
- 收益建筑：结算加成（+奖励比例）、被动收益（$ / 秒）

## 账号与奖励
- 账号注册/登录（密码加盐哈希），排行榜按破坏价值降序（云端+本地双存储）
- **每日登录奖励 +$20,000**（新玩家初始资金 $20,000）

## 载具
- 全部载具高耐久；**正常行驶/冲撞不消耗耐久（默认无限能源）**，仅受敌方攻击与爆炸损伤
- 载具被摧毁时**安全弹射落地继续行动**（短暂无敌），不会直接导致行动失败
- 骑乘中鼠标/右半屏可**自由调整环绕视角**

## 运行
- 电脑：双击 `启动游戏.bat`（或直接用 Chrome/Edge 打开 `index.html`）
- 手机：横屏用浏览器打开在线链接即可
- 存档保存在浏览器 localStorage；排行榜云端存储（免注册 KV 服务，个人项目）

## 技术说明
- 物理引擎 cannon.js + 渲染 three.js，全部本地运行、无外部网络依赖
- 超大世界（13.5 km²、约 2.8 万可破坏刚体）：网格宽阶段 + 网格DDA射线、
  多分辨率四叉树地面、AABB 范围空间索引
- 残骸数量有性能上限（约1100块），超出后最早的残骸沉入地面回收
